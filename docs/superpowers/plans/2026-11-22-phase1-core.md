# Ten Deep — Phase 1 (Core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable web and mobile build of the core loop: pick Current Day mode, spin and draft 10 under the cap, sim an 82-game season with injuries and a trade deadline, play the playoffs game by game, see the result.

**Architecture:** An Expo Router app (TypeScript) with a pure, seeded engine in `src/engine` that has no React, no network and no `Math.random`. UI state lives in a small zustand store that calls the engine. Data lives in TS modules under `src/data`. Settings persist locally in Phase 1; Supabase arrives in Phase 3.

**Tech Stack:** Expo SDK (latest stable), expo-router, react-native-web, TypeScript strict, zustand, i18next + react-i18next + expo-localization, expo-haptics, vitest (engine tests), Web Audio API for synthesized sound effects (web; native audio in Phase 6).

**Spec:** `docs/superpowers/specs/2026-11-22-ten-deep-design.md`

## Global Constraints
- Overall ratings are integers from **64 to 99**. 99 is reserved for all-time peak seasons.
- Salary cap is **$150M for 10 players**. Salary comes from overall rating: 99≈50, 95≈42, 90≈30, 85≈20, 80≈12, 75≈6, 70≈3, 64≈1 ($M). Interpolate linearly between those points.
- Roster: starters PG, SG, SF, PF, C and 5 bench slots (any position). A player can fill their primary or secondary position.
- 2 respins per draft. Each player appears at most once per draft (and once per league).
- Season: 82 games; trade deadline after game 50; playoffs are 16 teams, best-of-7, 4 rounds.
- Calibration: an average team ≈ 41 wins; a strong draft ≈ 55–62; 70+ is rare; 82-0 ≤ 1 in 10,000; the best roster wins the title about 30–40% of the time.
- Engine functions take an explicit `Rng`. The same seed must give the same result.
- No real likenesses, no NBA or team logos. Team names appear as plain text city and nickname.
- Commit author: `RyanRaiSaini <RyanRaiSaini@users.noreply.github.com>`. Push after each task.

## Review Focus
1. **Cap dead-end:** the player spends so much that the remaining slots can't be filled at minimum salary. Expected: the UI disables any pick that would cause it (`canAfford` reserves $1M per open slot). Test in Task 3.
2. **A spin with no eligible player** (all filtered by slot or cap). Expected: the UI says so and offers a respin; with 0 respins left, it offers the cheapest eligible player league-wide at minimum salary. Test in Task 4.
3. **Injury wipes out a position:** the sim must always field 5 players. Expected: out-of-position fill with a penalty. Test in Task 6.
4. **Refresh or close mid-draft or mid-sim:** state is lost. Phase 1 accepts this, but the draft is persisted to local storage so it doesn't crash on reload. Store test in Task 9.
5. **Arabic (RTL) layout:** text and rows must flip. Expected: `I18nManager`/`dir="rtl"` on web. Checked in Task 10 by rendering the home screen with `ar` in a Playwright screenshot.

### Task 2: Engine core types and seeded RNG
**Files:** `src/engine/types.ts`, `src/engine/rng.ts`, `src/engine/rng.test.ts`
**Produces:**
- `type Pos = 'PG'|'SG'|'SF'|'PF'|'C'`
- `interface Player { id: string; name: string; pos: Pos; pos2?: Pos; ovr: number; off: number; def: number; reb: number; ast: number; three: number; dur: number; age?: number; tag?: string; stats?: { ppg: number; rpg: number; apg: number }; accolades?: string[] }`
- `interface TeamSeason { id: string; label: string; city: string; name: string; season: string; colors: [string, string]; players: Player[] }`
- `interface Pool { id: string; label: string; teams: TeamSeason[] }`
- `interface Rng { next(): number; int(min: number, max: number): number; pick<T>(arr: T[]): T; normal(mean: number, sd: number): number; fork(salt: string): Rng }`
- `createRng(seed: string | number): Rng`, mulberry32 seeded via cyrb53 string hash.
- [ ] Tests: the same seed gives an identical sequence over 1,000 draws; different seeds differ; `int(1,6)` covers 1..6 only; `fork('a')` is deterministic and differs from the parent.
- [ ] Implement, run tests, commit: `feat(engine): seeded rng and core types`.

### Task 4: Draft state machine
**Files:** `src/engine/draft.ts`, `src/engine/draft.test.ts`
**Consumes:** Tasks 2 and 3. **Produces:**
- `type SlotId = 'PG'|'SG'|'SF'|'PF'|'C'|'B1'|'B2'|'B3'|'B4'|'B5'`; `type RosterSlots = Partial<Record<SlotId, Player>>`
- `interface DraftState { poolId: string; seed: string; round: number; respinsLeft: number; roster: RosterSlots; used: Set<string>; spin: TeamSeason | null }`
- `startDraft(pool: Pool, seed: string): DraftState`
- `spin(state, pool, rng): DraftState` lands on a team that has at least 1 unused player.
- `respin(state, pool, rng): DraftState`, which throws if `respinsLeft === 0`.
- `eligibleSlots(state, p): SlotId[]`
- `options(state): { player: Player; slots: SlotId[]; affordable: boolean }[]`
- `pick(state, playerId, slot): DraftState`, which throws on an ineligible slot or an unaffordable player.
- `fallbackPick(state, pool): Player`, the cheapest eligible unused player anywhere.
- `isComplete(state): boolean`
- [ ] Tests: a full 10-pick draft completes; a player can't be picked twice; a C-only player can't take the PG slot but can take B1; respins decrement and then throw; `fallbackPick` returns an affordable eligible player (Review Focus 2); the same seed gives the same spins.
- [ ] Implement, test, commit: `feat(engine): draft state machine`.

### Task 5: AI league drafter
**Files:** `src/engine/aiDraft.ts`, `src/engine/aiDraft.test.ts`
**Produces:** `draftLeague(pool: Pool, exclude: Set<string>, count: number, rng: Rng): Roster[]`, where `interface Roster { id: string; name: string; colors: [string,string]; slots: Required<RosterSlots> }`
- Strategy: round-robin snake draft over the whole pool. Each AI team values a player at `ovr + noise(sd 3)` minus a penalty if it would break the cap, fills starters first, and has a random "budget style" (stars-and-scrubs or balanced). That spreads team strength out.
- [ ] Tests: produces `count` full, legal rosters (cap respected, no duplicates, no excluded players); team average overalls have a standard deviation > 1.5 (there are good and bad teams).
- [ ] Implement, test, commit: `feat(engine): AI league drafter`.

### Task 6: Game simulation
**Files:** `src/engine/game.ts`, `src/engine/rotation.ts`, `src/engine/game.test.ts`
**Produces:**
- `lineupMinutes(roster: Roster, out: Set<string>): { player: Player; slot: SlotId; minutes: number; outOfPosition: boolean }[]`. Minutes sum to 240. Starters get about 30–36 and bench players 8–24, by rating. Players who are out get redistributed. Out-of-position players get a −4 effective overall penalty.
- `teamStrength(lineup): { off: number; def: number }`, weighted by minutes.
- `simGame(home: Roster, away: Roster, ctx: { rng: Rng; outHome: Set<string>; outAway: Set<string> }): GameResult`, where `interface GameResult { homeScore: number; awayScore: number; box: { playerId: string; pts: number; reb: number; ast: number; min: number }[] }`
- Model: about 100 possessions ± pace noise. Points per possession come from offense minus defense through a logistic curve, with home court worth +1.5 points. No ties (overtime loop). The exact coefficients are tuned in Task 8.
- [ ] Tests: minutes sum to 240 even with 4 players out (Review Focus 3); scores are in the 85–150 range over 500 sims; a stronger team wins more than 50% over 500 sims; deterministic per seed.
- [ ] Implement, test, commit: `feat(engine): possession-based game sim with rotation`.

### Task 7: Season, injuries, trade deadline, playoffs
**Files:** `src/engine/season.ts`, `src/engine/injuries.ts`, `src/engine/playoffs.ts`, tests alongside
**Produces:**
- `rollInjury(p: Player, minutes: number, rng): Injury | null`, where `Injury = { playerId; games: number; label: 'Day-to-day'|'Short-term'|'Long-term'|'Season-ending' }`. Per-game risk is about `0.004 × (minutes/30) × (1.6 − dur/100)`.
- `createSeason(user: Roster, league: Roster[], seed): SeasonState`, where the schedule is 82 games per team (round-robin plus random fill).
- `advance(state, games: number): SeasonState`, which stops at the deadline (game 50) and at the end of the season.
- `tradeSwap(state, outId, inPlayer): SeasonState`
- `standings(state)`
- `startPlayoffs(state): PlayoffState` with the top 16 seeded 1v16 (single table)
- `playNextGame(ps): PlayoffState`
- `champion(ps)`
- [ ] Tests: every team plays exactly 82 games; injured players miss the right number of games; `advance` stops at game 50; a playoff series ends at 4 wins; there's one champion.
- [ ] Implement, test, commit: `feat(engine): season, injuries, deadline, playoffs`.
